# 职业咨询工具互操作约定（能力优先、接入可选）

本文件是通用接口语义说明，不是某一种外部工作台的安装教程，也不是特定网络协议的规范。**SKILL 可独立执行；外部能力只在真实可用、获授权且可验证时使用。** 未实现此格式的工具仍可按相同专业规则使用，不能把 JSON 契约当作强制依赖。

## 一、任务与能力解耦

- `research`：公共政策、行业、企业与 JD 信息检索，带原始来源、地区、事实时间、检索时间。
- `evidence_validation`：核对来源、文本字段、独立上游、冲突和命题适用边界。
- `job_analysis`：按职责/层级抽取 JD、硬门槛、样本去重与时间状态。
- `financial_calculation`：基于本人确认的数字计算现金跑道、成本或成熟投递批次。
- `career_state`：在本人授权及真实写入成功后记录事实变更、计划和复盘版本。
- `decision_audit`：核查关键前提、授权、高成本风险与建议放行门槛。

Agent 只在当前任务需要时检查以上能力；**不必主动加载所有接口，也不必向求职者展示内部能力表**。

## 二、发现—授权—调用—核验—降级

1. **发现**：阅读当前运行环境实际公开的工具描述；如果存在能力清单，可用 `capability_manifest.schema.json` 校验其结构。能力清单只是提供者的自述。
2. **授权**：区分公共只读数据、私人资料读取、持久化写入、对外发送与账户更改。后几类依实际权限及用户同意执行；不把能力可用视为已经授权。
3. **调用**：记录执行的工具、实际输入、时间和返回状态；失败或未尝试不得记录为成功。不得以同名方法或工具自述替代真实执行事件。
4. **核验**：对返回值做字段、单位、样本、时效与来源检查；工具标签“已核验”仍需与原始证据关联。涉及现金、法定资格、不可逆行动时采用失败关闭。
5. **降级**：可用替代工具则合法替代；只能依靠已有资料时标注未核验；缺少必要私人事实才简短询问；高成本门槛未核实不得放行高成本行动。

## 三、可选交换文件

| 文件 | 含义 | 不代表 |
| --- | --- | --- |
| `capability_manifest.schema.json` | 具备何种能力、权限需求与限制的自述 | 接口已经可调用、用户已经授权 |
| `execution_state.schema.json` | 某一时刻的动作、建议状态及执行事件 | 真实网络请求已经发生、来源事实正确 |
| `career_case.schema.json` | 来源→命题→建议及个人能力证据的结构化记录 | 职业建议已经适用、求职者已经确认 |

`independent` 使用已有能力；`enhanced` 表示实际已使用并有成功事件的额外能力；`degraded` 表示环境限制下的保守执行。三者不是不同产品、不同安装包或不同流程。不要仅凭模式名断言任何具体工具在场。

## 四、兼容性与验收

- 提供者可以用 MCP、普通函数、命令行、HTTP 或其他合法通道实现能力。**不存在必须实现的服务名、固定端点或统一数据库。**
- 工具升级时检查输入字段、单位、状态语义、证据引用、授权与错误码是否兼容；不以两端版本号相等判断兼容性。
- 测试 `available→timeout`、来源冲突、权限拒绝、写入失败、非数值结果、重试上限及高成本动作阻断。
- 可使用 `tools/validate_runtime.py` 检查结构及确定性门槛；真实工具编排须在有事件日志的环境中单独验收。
- 外部工具、模型和用户都不能跳过原定的来源—命题—建议三层核验与最终本人决策。
